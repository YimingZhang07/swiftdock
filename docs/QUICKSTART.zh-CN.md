# QuickLaunch v0.1.3

Windows x64 启动器。standalone 包无需另装 .NET；解压整个目录后双击 `QuickLaunch.exe`，不要只移动 exe。

诊断日志默认位于 `%LOCALAPPDATA%\QuickLaunch\logs`（便携模式为程序旁的 `logs`），可用 `--diagnostics-dir <目录>` 覆盖。格式为 CLEF：按 `EventId.Name` 筛选事件，字段直接位于顶层。多个进程可共享同一目录的滚动文件；Serilog 按日期/约 4 MiB 滚动、保留 20 个匹配文件。读取最新滚动文件及分段后，按 `Pid` 和 GUID `Session` 筛选会话。详见 [日志与启动测量](LOGGING.md)。E2E 启动记录仍使用独立 JSONL；旧程序内 smoke 已移除。

## 日常操作

1. 默认按 **Alt+Space** 显示面板，单击图标或用方向键选择后按 Enter 启动。启动项目、点击其他窗口后面板保持显示；点击右上角 ×、未打开右键菜单、未拖动且无选择时按 Esc，或在面板已激活时再次按热键可隐藏。有选择时按 Esc 先清除选择，再按一次隐藏。单行顶栏的空白处可拖动窗口；边缘及四角可调整大小，位置和大小会自动记住，下次呼出恢复。设置 → 外观 → 呼出位置可选“上次位置”（默认）或“跟随鼠标”；原屏幕断开时自动按鼠标所在屏幕定位。
2. 点击右上角“添加项目”，再点击“应用 / 文件 / 文件夹 / 网址”类型卡片录入目标；文件夹可点桌面、下载等常用位置，应用的参数、工作目录和管理员选项在“高级选项”中。粘贴网址或已有路径会自动识别类型，也可直接从资源管理器或浏览器拖入。顶栏左侧切换分组，滚轮可横向滚动分组；分组后的 + 用于新建分组。
3. 拖动图标排序，悬停其他标签 400ms 后跨组放置，拖到“+”创建新组。拖动标签可调整组顺序。Esc 或在窗口外松开取消移动。
4. 右键条目可编辑、重命名、删除、打开所在位置或刷新图标；“更换图标…”直接打开图标选择器。也可在添加/编辑时点击名称旁的图标，从 60 个系统字形和 8 种底色中选择，或“从文件选择…” ICO、PNG、JPG、BMP、EXE、DLL。“恢复默认”还原目标图标；保存后生效，取消编辑不改动原项目。应用可单独以管理员身份启动。
5. 删除后 5 秒内 Ctrl+Z 可撤销最近一次单条删除。删除非空分组需要确认，整组删除不能通过单条撤销恢复。
6. 点击顶栏齿轮打开“设置”，按“快捷键 / 外观 / 启动”卡片调整。快捷键选好后点“应用”；Windows 拒绝新热键时旧组合继续保留，初始冲突可从托盘进入设置。图标默认小（32 DIP），可选中（40 DIP）或大（48 DIP），立即生效并自动保存；在图标区按住 **Ctrl + 滚轮** 也可逐档调整，拖动或只读时不修改尺寸。“登录 Windows 时自动启动”开关位于“启动”区，切换即生效。
7. 外观中的“主题”可选跟随系统、浅色或深色；“背景材质”可选亚克力、云母或纯色；“强调色”可选跟随系统或蓝、青、绿、紫、玫红、橙、石板灰，圆形色块悬停显示名称，选中显示外圈。选择立即生效并自动保存，只读配置不可修改。
8. 改变图标大小时，已保存的窗口大小保持不变，列数随之重排并均匀分布；未保存大小时自动适配。设置中的“恢复默认位置和大小”会清除手动位置和尺寸，将可见面板移回当前屏幕的默认位置并立即适配内容。

键盘：呼出面板或鼠标切组后为未选择；首次方向键、Home/End 或 PageUp/PageDown 选择首项，之后方向键按行列移动，Home/End 到首尾，PageUp/PageDown 移动一视口页。Enter 启动所选项（长按不重复），F2 重命名、Delete 删除所选项；未选择时这三个键均无操作。单击图标启动后或点击图标区空白处清除选择。Ctrl+Tab / Ctrl+Shift+Tab 切组，Ctrl+1…9 跳组，均选择新组首项；Tab 在分组列表、标签和顶栏按钮间移动焦点。Ctrl+Z 撤销删除。Esc 优先关闭已打开的右键菜单或取消拖动；否则有选择时只清除选择，面板保持显示、焦点留在列表，下一次方向键重新选择首项；无选择时隐藏面板。编辑框内的快捷键只编辑文本。

图标选择器内方向键移动焦点，空格/Enter 选择，Tab 切换字形、颜色和文件/默认操作；Esc 或点击外部关闭。图标文件使用原路径，不复制到配置目录，丢失时自动显示默认图标。Windows 10 会隐藏备用字体不支持的字形。

面板由 48 DIP 单行顶栏和图标区组成，左右内边距与内容内边距均为 16 DIP；标签与首列图标对齐，图标列均匀分布。顶栏包含分组、添加项目、设置和隐藏按钮；拖动分组或图标不会移动整个窗口。删除、撤销、导入及错误会显示短暂提示条，导入期间可取消；成功启动、编辑和正常保存不会弹出提示。设置底部的配置目录可选择并复制。

## 数据与退出

- 配置默认位于 `%APPDATA%\QuickLaunch`，可从托盘打开目录；备份为 `config.json.bak`。
- 添加、排序和设置自动保存；顶栏只显示只读或尚未保存的错误。退出时保存失败可重试或返回，强杀可能丢失最后尚未保存的修改。
- 在 exe 同目录建立 `portable.flag` 可使用便携模式，目录不可写会提示。移动目录前先关闭自启，移动后重新设置。
- 主题和强调色默认跟随系统，也可在设置中选择。Windows 高对比度始终优先，关闭后恢复自己的选择。未自定义的网址先显示地球，再异步显示网站图标；小图标居中放在浅色圆角底板上。自定义图标始终优先。
- 网站图标直接访问网址、跟随其 HTTP/HTTPS 重定向，并读取最终页面引用的图标（包括 CDN），不使用第三方图标查询服务。在设置 → 外观关闭“自动获取网站图标”开关即可停用，关闭后不发请求，也不使用缓存的网站图标。成功缓存 30 天，失败缓存 1 天；右键“刷新图标”可跳过缓存重新获取该站点。只读配置不能修改这个设置。
- × 仅隐藏面板并继续常驻；设置底部“退出 QuickLaunch”或托盘菜单“退出”才结束程序，退出前会保存最后修改。设置中的“关闭”只关闭设置窗口。
- 脚本可运行 `QuickLaunch.exe --exit --config-dir "D:\LauncherProfile"`，通过单实例管道请求同一配置正常退出并清除托盘图标。省略 `--config-dir` 时使用默认/便携目录。退出码 `0` 表示请求已确认，`2` 表示没有实例确认；命令不会新建配置或启动面板。保存失败仍会提示重试/取消，因此确认后进程可能尚未结束。

## 开发

标准按钮、输入框、开关、下拉框、菜单、提示和滚动条由 WPF-UI 4.3.0（MIT）提供，面板自定义样式使用同一套主题资源。主题与强调色通过 WPF-UI API 应用，深浅色变体由库生成。透明效果关闭、高对比度或系统不支持所选材质时，面板回退纯色，背景材质行显示原因。设置、项目编辑、名称和确认对话框使用无图标标题栏与 Mica；选择纯色时对话框也使用纯色，系统回退规则同样适用；删除分组的确认框以红色“删除”和“取消”区分操作。构建与验证命令见 [README](../README.md#开发)。

## 本版验证边界

功能已实现并通过自动检查。真实浏览器拖拽、混合 DPI、UAC、系统注销/关机及 Explorer 重启等人工场景尚未全部验证。性能报告中，后台前台权限失败不会计为成功；未承诺 50ms 端到端呼出或 60MB 常驻内存已全面达成。

## 开发验证

- 每次修改：`scripts/Validate.ps1`，锁定还原 + Release `-warnaserror` + 453 项快速单测，目标 ≤40 秒；默认不运行桌面检查。
- UI 改动后：解锁桌面运行 `scripts/E2E.ps1`，11 个真实键鼠用例，评审实测 11/11 通过（125 秒，已接受）。运行期间不要操作键鼠，详见 [E2E](E2E.md)。
- 视觉评审：解锁桌面按需运行 `scripts/Snapshots.ps1`，在 `artifacts/validation/` 生成 33 张 PNG 和 `snapshots.json`，只检查是否渲染成功。窗口在屏幕外渲染且不抢焦点，不需要点击对话框；单张图超时后继续，脚本默认 90 秒总时限，部分失败也写入 `snapshots.json`。

`--smoke-test`、`Run.ps1 -Smoke`、`Validate.ps1 -DesktopSmoke` 已删除。覆盖迁移、实测结果和沙箱限制见 [测试整合记录](validation/test-consolidation.md)。
