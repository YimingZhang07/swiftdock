# QuickLaunch v0.1.0

Windows x64 启动器。standalone 包无需另装 .NET；解压整个目录后双击 `QuickLaunch.exe`，不要只移动 exe。

## 日常操作

1. 默认按 **Alt+Space** 显示面板，单击图标或按 Enter 启动，再自动隐藏。Esc 和点击外部也可隐藏。
2. 点击“添加”录入程序/文件/文件夹/网址。拖入时可先勾选“保持显示以添加”，再到源窗口拖动文件或浏览器链接；完成后取消勾选。
3. 拖动图标排序，悬停其他标签 400ms 后跨组放置，拖到“+”创建新组。拖动标签可调整组顺序。Esc 或在窗口外松开取消移动。
4. 右键条目可编辑、重命名、删除、打开所在位置或刷新图标；应用可单独以管理员身份启动。启动器自身保持普通权限。
5. 删除后 5 秒内 Ctrl+Z 可撤销最近一次单条删除。删除非空分组需要确认，整组删除不能通过单条撤销恢复。
6. “设置”可改热键、失焦隐藏和登录自启。Windows 拒绝新热键时旧组合继续保留；初始冲突可从托盘进入设置。

键盘：方向键/Tab 移动焦点，Enter 启动，Ctrl+Tab / Ctrl+Shift+Tab 切组，Ctrl+1…9 跳组，F2 重命名，Delete 删除。编辑框内的快捷键只编辑文本。

## 数据与退出

- 配置默认位于 `%APPDATA%\QuickLaunch`，可从托盘打开目录；备份为 `config.json.bak`。
- 添加、排序和设置自动保存；顶栏确认“已保存”。退出时保存失败可重试或返回，强杀可能丢失最后尚未保存的修改。
- 在 exe 同目录建立 `portable.flag` 可使用便携模式，目录不可写会提示。移动目录前先关闭自启，移动后重新设置。
- 系统主题自动跟随，无需手动切换。URL 使用地球图标；低分辨率原图标不能凭插值恢复细节。
- “隐藏”会继续常驻；从面板或托盘选择“退出”才结束程序。

## 本版验证边界

功能已实现并通过自动检查。真实浏览器拖拽、混合 DPI、UAC、系统注销/关机及 Explorer 重启等人工场景尚未全部验证。性能报告中，后台前台权限失败不会计为成功；未承诺 50ms 端到端呼出或 60MB 常驻内存已全面达成。
