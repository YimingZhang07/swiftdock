# QuickLaunch 使用说明

Windows 10/11 x64 启动器，安装版和便携版均自带 .NET，无需另装运行时。

## 安装、便携与卸载

- **安装**：运行 `QuickLaunch-<版本>-Setup.exe`，在向导中选择安装路径。默认安装到 `%LOCALAPPDATA%\Programs\QuickLaunch`，仅供当前用户使用，无需管理员权限。自动创建开始菜单入口；桌面快捷方式默认不勾选，完成后的“启动 QuickLaunch”默认勾选。
- **SmartScreen**：安装包未签名；若出现“Windows 已保护你的电脑”，确认下载来源后点击“更多信息”→“仍要运行”。
- **便携**：将 `QuickLaunch-<版本>-Portable.zip` 解压到任意可写位置，双击 `QuickLaunch\QuickLaunch.exe`。程序旁的 `Data\` 文件夹必须保留：配置、`icons\` 缓存和 `logs\` 都放在 `Data\` 中，不写入 AppData。移动便携文件夹前先关闭登录自启，移动后再开启；移除前关闭自启并退出程序，再删除整个文件夹。
- **升级**：再次运行安装包，沿用之前选择的安装目录，用户数据不变。
- **卸载**：从 Windows“已安装的应用”卸载。卸载只移除该安装目录对应的登录自启项，然后询问是否也删除 `%APPDATA%\QuickLaunch` 的配置和 `%LOCALAPPDATA%\QuickLaunch` 的缓存/日志，默认“否”。静默卸载不删除数据；其他目录中的便携副本及其自启项保留。
- 安装、升级及卸载会请求 QuickLaunch 正常退出，保存配置并移除托盘图标。如果程序没有退出，请从托盘菜单退出后重试。

诊断日志默认位于 `%LOCALAPPDATA%\QuickLaunch\logs`（便携模式为 `Data\logs\`），可用 `--diagnostics-dir <目录>` 覆盖。格式为 CLEF：按 `EventId.Name` 筛选事件，字段直接位于顶层。多个进程可共享同一目录的滚动文件；Serilog 按日期/约 4 MiB 滚动、保留 20 个匹配文件。读取最新滚动文件及分段后，按 `Pid` 和 GUID `Session` 筛选会话。详见 [日志与启动测量](LOGGING.md)。

## 日常操作

默认 **Alt+Space** 呼出并激活隐藏面板；可见且已激活或置顶时一按即隐藏，未置顶且未激活时先前置激活、再按隐藏。

顶栏图钉切换置顶，默认开启，立即生效并自动保存；只读配置不可修改。

托盘图标单击切换面板（未置顶且原本未激活时先前置），系统双击时间内的连点只切换一次；设置打开及切换常规、外观、面板、关于页面均无滑入或淡入过渡。

1. 单击图标或用方向键选择后按 Enter 启动。启动项目、点击其他窗口后面板保持显示；点击右上角 ×，或未打开右键菜单、未拖动且无选择时按 Esc 可隐藏。有选择时按 Esc 先清除选择，再按一次隐藏。单行顶栏的空白处可拖动窗口；边缘及四角可调整大小，位置和大小会自动记住，下次呼出恢复。设置 → 外观 → 呼出位置可选“上次位置”（默认）或“跟随鼠标”；原屏幕断开时自动按鼠标所在屏幕定位。
2. 点击右上角“添加项目”，再点击“应用 / 文件 / 文件夹 / 网址”类型卡片录入目标；文件夹可点桌面、下载等常用位置，应用的参数、工作目录和管理员选项在“高级选项”中。粘贴网址或已有路径会自动识别类型，也可直接从资源管理器或浏览器拖入。顶栏左侧切换分组，滚轮可横向滚动分组；分组后的 + 用于新建分组。
3. 拖动图标排序，悬停其他标签 400ms 后跨组放置，拖到“+”创建新组。拖动标签可调整组顺序。Esc 或在窗口外松开取消移动。
4. 右键条目可编辑、重命名、删除、打开所在位置或刷新图标；“更换图标…”直接打开图标选择器。也可在添加/编辑时点击名称旁的图标，从 60 个系统字形和 8 种底色中选择，或“从文件选择…” ICO、PNG、JPG、BMP、EXE、DLL。“恢复默认”还原目标图标；保存后生效，取消编辑不改动原项目。应用可单独以管理员身份启动。
5. 删除后 5 秒内 Ctrl+Z 可撤销最近一次单条删除。删除非空分组需要确认，整组删除不能通过单条撤销恢复。
6. 点击顶栏齿轮打开“设置”，按“快捷键 / 外观 / 启动”卡片调整。快捷键选好后点“应用”；Windows 拒绝新热键时旧组合继续保留，初始冲突可从托盘进入设置。图标默认小（32 DIP），可选中（40 DIP）或大（48 DIP），立即生效并自动保存；在图标区按住 **Ctrl + 滚轮** 也可逐档调整，拖动或只读时不修改尺寸。“登录 Windows 时自动启动”开关位于“启动”区，切换即生效。
7. 外观中的“主题”可选跟随系统、浅色或深色；“背景材质”可选亚克力、云母或纯色；“强调色”可选跟随系统或蓝、青、绿、紫、玫红、橙、石板灰，圆形色块悬停显示名称，选中显示外圈。选择立即生效并自动保存，只读配置不可修改。
8. 改变图标大小时，已保存的窗口大小保持不变，列数随之重排并均匀分布；未保存大小时自动适配。设置中的“恢复默认位置和大小”会清除手动位置和尺寸，将可见面板移回当前屏幕的默认位置并立即适配内容。

键盘：呼出面板或鼠标切组后为未选择；首次方向键、Home/End 或 PageUp/PageDown 选择首项，之后方向键按行列移动，Home/End 到首尾，PageUp/PageDown 移动一视口页。Enter 启动所选项（长按不重复），F2 重命名、Delete 删除所选项；未选择时这三个键均无操作。单击图标启动后或点击图标区空白处清除选择。Ctrl+Tab / Ctrl+Shift+Tab 切组，Ctrl+1…9 跳组，均选择新组首项；Tab 在分组列表、标签和顶栏按钮间移动焦点。Ctrl+Z 撤销删除。Esc 优先关闭已打开的右键菜单或取消拖动；否则有选择时只清除选择，面板保持显示、焦点留在列表，下一次方向键重新选择首项；无选择时隐藏面板。编辑框内的快捷键只编辑文本。

图标选择器内方向键移动焦点，空格/Enter 选择，Tab 切换字形、颜色和文件/默认操作；Esc 或点击外部关闭。图标文件使用原路径，不复制到配置目录，丢失时自动显示默认图标。Windows 10 会隐藏备用字体不支持的字形。

面板由 48 DIP 单行顶栏和图标区组成，内容上方和左右内边距为 16 DIP，底部预留 24 DIP 状态文字区；标签与首列图标对齐，图标列均匀分布。顶栏包含分组、添加项目、设置、置顶和隐藏按钮；拖动分组或图标不会移动整个窗口。删除、撤销、导入及错误以 12 DIP 单行文字显示在图标区下方，过长时省略，导入期间可点击“取消”；成功启动、编辑和正常保存不会弹出提示。设置底部的配置目录可选择并复制。

## 数据与退出

- 配置默认位于 `%APPDATA%\QuickLaunch`，可从托盘打开目录；备份为 `config.json.bak`。
- 添加、排序和设置自动保存；顶栏只显示只读或尚未保存的错误。退出时保存失败可重试或返回，强杀可能丢失最后尚未保存的修改。
- exe 同目录的 `Data\` 启用便携模式；不可写时可选择使用默认目录、只读运行或退出。`--config-dir <绝对目录>` 优先于便携模式，改用指定配置及默认缓存/日志目录。
- 主题和强调色默认跟随系统，也可在设置中选择。Windows 高对比度始终优先，关闭后恢复自己的选择。未自定义的网址先显示地球，再异步显示网站图标；小图标居中放在浅色圆角底板上。自定义图标始终优先。
- 网站图标直接访问网址、跟随其 HTTP/HTTPS 重定向，并读取最终页面引用的图标（包括 CDN），不使用第三方图标查询服务。在设置 → 外观关闭“自动获取网站图标”开关即可停用，关闭后不发请求，也不使用缓存的网站图标。成功缓存 30 天，失败缓存 1 天；右键“刷新图标”可跳过缓存重新获取该站点。只读配置不能修改这个设置。
- × 仅隐藏面板并继续常驻；设置底部“退出 QuickLaunch”或托盘菜单“退出”才结束程序，退出前会保存最后修改。设置中的“关闭”只关闭设置窗口。
- 脚本可运行 `QuickLaunch.exe --exit --config-dir "D:\LauncherProfile"`，通过单实例管道请求同一配置正常退出并清除托盘图标。省略 `--config-dir` 时使用默认/便携目录。退出码 `0` 表示请求已确认，`2` 表示没有实例确认；命令不会新建配置或启动面板。保存失败仍会提示重试/取消，因此确认后进程可能尚未结束。

## 开发

标准按钮、输入框、开关、下拉框、菜单、提示和滚动条由 WPF-UI 4.3.0（MIT）提供，面板自定义样式使用同一套主题资源。主题与强调色通过 WPF-UI API 应用，深浅色变体由库生成。透明效果关闭、高对比度或系统不支持所选材质时，面板回退纯色，背景材质行显示原因。设置、项目编辑、名称和确认对话框使用无图标标题栏与 Mica；选择纯色时对话框也使用纯色，系统回退规则同样适用；删除分组的确认框以红色“删除”和“取消”区分操作。构建与验证命令见 [README](../README.md#开发)。

开发者在仓库根目录运行 `scripts/Setup.ps1` 安装本地 SDK 和便携 Inno Setup，再运行 `scripts/Release.ps1` 验证并发布。`-SkipTests` 跳过单测验证；`-E2E` 额外运行真实桌面检查（即使同时指定 `-SkipTests`）。产物在 `artifacts/release/<版本>/`：安装器、便携 ZIP 和 `SHA256SUMS.txt`；同版本每次重建覆盖。单文件 exe 位于 `artifacts/staging/<版本>/`，可传给 `Benchmark.ps1 -Executable` 和 `MeasureStartup.ps1 -Executable`。修改 `QuickLaunch/QuickLaunch.csproj` 的 `<Version>` 即可升级版本，关于页、exe、安装器及文件名都会随之更新；当前版本为 `1.1.0`。

## 开发验证

- 每次修改：`scripts/Validate.ps1`，锁定还原 + Release `-warnaserror` + 快速单测；默认不运行桌面检查。
- UI 改动后：解锁桌面运行 `scripts/E2E.ps1` 的真实键鼠用例。运行期间不要操作键鼠，详见 [E2E](E2E.md)。
- 视觉评审：解锁桌面按需运行 `scripts/Snapshots.ps1`，在 `artifacts/validation/` 生成 41 张 PNG 和 `snapshots.json`，检查渲染及深色设置文字对比度。窗口在屏幕外渲染且不抢焦点，不需要点击对话框；单张图超时后继续，脚本默认 90 秒总时限，部分失败也写入 `snapshots.json`。
