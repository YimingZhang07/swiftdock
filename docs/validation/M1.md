## 功能与实现

- 配置模型使用 System.Text.Json 源生成，校验版本、必需字段、ID 唯一性、类型和布局值。未知更高版本只读；未知字段、缺失 ID 和损坏条目不静默丢弃。
- MainViewModel 在 UI 线程生成快照，500ms 防抖交给单消费者写入队列。待处理快照按最新 revision 合并，旧 revision 不覆盖新状态。写入临时文件后 Flush(true)，使用 File.Replace/Move 提交；失败保留原文件及未保存状态。
- 恢复先保留损坏原件，再从备份恢复；不会用坏正式文件覆盖完好备份。正常退出异步保存，失败可选择重试/放弃/返回；OS 结束会话只进行最多 800ms 的尽力保存，不无限阻止关机。
- 单实例按用户、登录会话和规范配置目录区分。以命名 Mutex 的对象存活期标记首实例，避免 async 后跨线程释放所有权；第二实例只短暂检查，不持有标记阻止原实例退出后的接管。
- 当前用户限定的命名管道发送固定长度 PID/Show/ACK。初始化中的请求进入 UI 队列；退出中的实例拒绝新请求，原实例在转发前结束时第二实例可原子接管。配置写锁独立于 UI 实例，用于防止跨会话同时写入。
- 设置窗口可改全局热键和失焦隐藏。先注册候选组合再释放旧组合，失败保留旧入口；设置由主窗口拥有，关闭设置不会退出常驻程序。
- 已有添加、排序、分组选择接入保存；拖拽悬停切组仍只是预览。Shell 启动成功更新计数；失败条目显示可重试的错误标记/提示，错误状态不写进配置。
- 可从托盘打开设置、显示主窗口、保持显示以添加或打开配置目录。新增“只读/等待保存/保存中/已保存/尚未保存”状态。

## 复现

```powershell
.\scripts\Validate.ps1 -DesktopSmoke
.\scripts\Run.ps1
```

正常运行默认使用 `%APPDATA%\QuickLaunch`，可在托盘打开配置目录。新增/排序后查看“已保存”，退出再启动核对顺序；设置里更换热键，并用其他实例/工具占用候选组合观察原热键保留。手工编辑 JSON 前必须退出应用，M1 无配置热重载。

自动检查始终新建 `artifacts/m1/profiles/smoke-<guid>`。直接启动发布 exe 做检查时，需要 `--smoke-test --config-dir <独立测试目录> --diagnostics-dir <日志目录>` 并确保能找到 .NET 10 Windows Desktop Runtime。

尚未验证的浏览器拖放、管理员窗口/菜单激活、混合 DPI、UAC 和 OS 结束会话，继续按 M0 的人工步骤及本计划执行。不得把 37 个测试或 18 个桌面检查代替这些场景。

## 后续边界

本阶段未实现 M2 图标缓存/预热优化，也未声称达到 50ms P95。M0 保留的基础导入和拖拽可用并会保存，但完整去重、占位队列、自动滚动、动画、条目编辑和撤销仍按后续里程碑完成。M2 前继续保留上述未验证项，不进行输入注入、线程输入附加或为了内存数字强制 GC。
